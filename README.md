Вместо плоского чёрного фона — тёплый «асфальтовый» тёмный (#14181C/#0D1013), золотой акцент (#E8B33D, теплее и спокойнее, чем чистый жёлтый) и дополнительный холодный бирюзовый (#3FA9A0) — ассоциация с водой и пеной. Заголовки набраны шрифтом Big Shoulders Display (плотный, «дорожно-гаражный» характер), текст — Manrope. Логотип показан статично, в круглой рамке (в шапке, hero-блоке, «О компании» и футере) — без анимации.


Логотип на сайте — не фотография, а простая SVG-иконка машины, нарисованная прямо в `index.html` (символ `#car-icon`) и стилизованная в CSS через `.logo-badge`/`.car-icon`. Файл `images/logo.jpg` используется только как иконка вкладки браузера (favicon) и как исходник для сверки. Чтобы заменить иконку на другую картинку, замените содержимое символа `#car-icon` или поменяйте разметку `.logo-badge` на `<img>`.

## 6. Публикация

### GitHub Pages
1. Создайте новый репозиторий на GitHub и загрузите в него содержимое папки `k013-site/` (файлы `index.html`, `style.css`, `script.js`, папку `images/`).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/<название-репозитория>/`.

### Vercel
1. Загрузите папку `k013-site/` в репозиторий на GitHub (или GitLab/Bitbucket).
2. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New → Project** и выберите этот репозиторий.
3. Framework Preset — оставьте **Other** (сайт статический, сборка не нужна), Build Command и Output Directory можно оставить пустыми.
4. Нажмите **Deploy** — Vercel выдаст рабочую ссылку через несколько секунд.

Оба варианта не требуют сервера или базы данных — сайт полностью статический.
