## 2. Концепция дизайна

Не копирует чёрно-жёлтую визитку буквально. Вместо плоского чёрного фона — тёплый «асфальтовый» тёмный (#14181C/#0D1013), золотой акцент (#E8B33D, теплее и спокойнее, чем чистый жёлтый) и дополнительный холодный бирюзовый (#3FA9A0) — ассоциация с водой и пеной. Заголовки набраны шрифтом Big Shoulders Display (плотный, «дорожно-гаражный» характер), текст — Manrope.

Используются два разных лого-изображения: крупная круглая эмблема в hero-блоке (`logo.png`, не менялась) и более лёгкая, скетчевая иллюстрация «пистолет мойки + машина» (`logo-mark.png`) — как маленький фирменный значок в шапке и футере. Исходный рисунок для маленькой эмблемы был очень бледным (тонкий карандашный скетч, почти невидимый уже на белом фоне) — при таком слабом контрасте на 36–44px он полностью терялся. Файл `logo-mark.png` поэтому пересобран: линии переведены в жирный чёрно-графитовый контур на прозрачном фоне, чтобы значок оставался читаемым даже в самом маленьком размере. Оба лого показаны на светлом круглом «чипе», статично, без анимации.

По нижнему краю hero-блока — silhouette панорамы города (`city-skyline.png`), очень приглушённая (непрозрачность ~16%): исходная картинка — чёрные линии на белом фоне, поэтому она инвертирована и наложена через `mix-blend-mode: screen`, чтобы белый фон исчез и остались только бледные светлые линии зданий на тёмном фоне. Кадрирование настроено так, чтобы показывать именно силуэт застройки (верхнюю/среднюю часть картинки — небоскрёбы, мост), а не нижнюю полосу с отражением в воде.

## 4. Структура проекта

```
k013-site/
├── index.html
├── style.css
├── script.js
├── README.md
├── favicon.ico             ← иконка вкладки браузера (16/32/48px) — мыльный пузырь
├── favicon-16.png
├── favicon-32.png
├── apple-touch-icon.png    ← иконка для iOS «На экран Домой» (180×180)
└── images/
    ├── logo.png               ← крупный логотип (hero-блок, не менялся)
    ├── logo-mark.png           ← маленькая эмблема (шапка, футер) — пистолет мойки + машина
    ├── city-skyline.png        ← панорама города — фон по низу hero-блока
    ├── card-front.jpg         ← фото визитки, лицевая сторона (исходник)
    ├── card-back.jpg          ← фото визитки, обратная сторона (исходник)
    └── price-list-source.jpg  ← фото прайс-листа (исходник, для сверки)
```

Логотипы — PNG с прозрачным фоном (непрозрачны только чёрные линии рисунка), поэтому на странице всегда лежат на светлом круглом фоне (класс `.logo-mark` в `style.css`). Крупный логотип (`logo.png`) показан целиком (`object-fit: contain`); маленькая эмблема (`logo-mark.png`) — широкая иллюстрация, поэтому обрезается по центру (`object-fit: cover`, класс `.logo-mark-img--cover`), чтобы деталь не терялась в мелком размере. Чтобы заменить любой из логотипов, положите новый файл в `images/` под тем же именем, либо поменяйте путь `src=` в `index.html` (`logo.png` — 1 место, `logo-mark.png` — 2 места: шапка и футер).

Favicon сделан отдельно от логотипов: мелкий рисунок неразборчив при 16–32 пикселях, поэтому для вкладки браузера нарисована отдельная крупная простая иконка — мыльный пузырь (бирюзовый круг с белым бликом и маленьким «спутником»-пузырьком) на тёмном фоне. Чтобы заменить favicon, положите свои файлы `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` в корень проекта под теми же именами.

## 6. Публикация

### GitHub Pages
1. Создайте новый репозиторий на GitHub и загрузите в него **всю папку `k013-site/` целиком, сохранив структуру** (`index.html`, `style.css`, `script.js`, favicon-файлы и папку `images/` со всеми картинками внутри — не по отдельности).
2. В репозитории откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку `main` и папку `/ (root)`.
4. Сохраните — через 1–2 минуты сайт будет доступен по адресу вида `https://<ваш-логин>.github.io/<название-репозитория>/`.

### Vercel
1. Загрузите папку `k013-site/` в репозиторий на GitHub (или GitLab/Bitbucket).
2. Зайдите на [vercel.com](https://vercel.com), нажмите **Add New → Project** и выберите этот репозиторий.
3. Framework Preset — оставьте **Other** (сайт статический, сборка не нужна), Build Command и Output Directory можно оставить пустыми.
4. Нажмите **Deploy** — Vercel выдаст рабочую ссылку через несколько секунд.

Оба варианта не требуют сервера или базы данных — сайт полностью статический.
